# 越野智赛——Android定向赛一站式平台



## 一、项目概述

**项目名称**：越野智赛——Android定向赛一站式平台
**项目定位**：面向校园及城市轻量级定向越野赛事，提供集赛事创建、路线规划、实时定位、电子打卡、成绩统计与数据导出于一体的移动端数字化解决方案。
**核心价值**：通过移动互联网技术，解决传统定向越野赛事中存在的效率低、数据统计滞后、体验差等问题，实现赛事全流程数字化管理。



## 二、项目背景与需求分析

### 1. 传统赛事痛点
- 依赖纸质地图与人工打卡，效率低下，易出错。
- 数据统计滞后，选手体验差，主办方管理成本高。

### 2. 移动互联网机遇
- 参赛者期望实时定位、电子打卡、成绩同步。
- 主办方需通过技术手段降低人力成本，提升赛事可控性与数据可视化。

### 3. 目标用户与场景
- **用户角色**：管理员（教师/组织者）、选手（学生/参赛者）。
- **典型场景**：校园定向周、体育课程竞赛、城市轻量级定向活动。



## 三、项目目标与核心功能

### 1. 总体目标
开发一款基于Android的APP，实现：
- 管理员：赛事创建、路线编辑、成绩发布与导出。
- 选手：路线获取、实时定位、电子打卡、成绩查看。
- 观众：赛事浏览与排行榜查看。

### 2. 核心功能清单
- **赛事管理**：创建赛事、设置起终点与检查点、设定规则与关门时间、自动生成路线缩略图。
- **路线编辑**：地图上点击添加点位、智能类型推荐、支持高德地图搜索定位、路线预览。
- **实时定位与轨迹显示**：基于高德地图SDK，显示当前位置与赛道、支持轨迹回放。
- **双模打卡机制**：GPS自动打卡 + 二维码辅助验证，支持离线保存与云端自动同步。
- **成绩统计与排名**：自动计算耗时、智能排名（进行中动态更新、结束后锁定）、支持条件筛选。
- **数据导出**：支持CSV格式导出，便于Excel处理。
- **数据同步**：Realm本地存储 + LeanCloud云端备份，支持离线操作与多设备同步。
- **文件分享**：二维码保存到相册与跨应用分享。
- **异常处理**：GPS信号弱时可手动补录，标记异常情况。



## 四、系统架构与技术路线

### 1. 系统架构
采用**MVC架构**：
- **Model**：管理用户、赛事、打卡记录等数据，使用Realm本地数据库。
- **View**：界面展示，包括地图、轨迹、成绩等。
- **Controller**：处理用户操作与业务逻辑，如赛事管理、打卡验证。

### 2. 数据架构
- **本地存储**：Realm数据库，支持离线操作和数据加密。
- **云端备份**：LeanCloud云数据库，支持多设备数据同步。
- **同步策略**：本地优先写入，后台异步同步到云端，网络恢复自动增量同步。

### 3. 核心技术栈
- **开发语言**：Java
- **地图服务**：高德地图SDK（3DMap + Search + Location）
- **本地数据库**：Realm（v10.15.1）
- **云端数据库**：LeanCloud（v8.2.28）
- **图片加载**：Glide（v4.16.0）
- **二维码**：ZXing（v3.5.0）
- **异步处理**：RxJava 2（v2.1.1）

### 4. 关键技术实现
- **定位技术**：高德地图SDK，精度约10米，支持轨迹回放与地图搜索。
- **打卡逻辑**：GPS圆形地理围栏 + 二维码双重验证，异常情况下支持手动补录。
- **数据安全**：Realm数据库内置加密，支持数据清除与隐私保护。
- **地图截图**：自动生成赛事路线缩略图，Bitmap深拷贝避免SDK回收问题。
- **智能排名**：赛事进行中动态排名，结束后排名锁定不再变化。
- **缩略图加载**：支持回退路径推算，即使DB字段丢失也能按raceId自动查找本地文件。

### 1. 赛事管理模块
- 管理员通过向导式界面创建赛事，设置名称、时间、检查点等。
- 地图上长按添加点位，支持拖拽调整与删除。

### 2. 选手端定位与打卡模块
- 加载赛事路线后，地图显示赛道与检查点。（Haversine公式），结合GPS+二维码验证 |
| 离线数据同步     | 本地Realm数据库优先，网络恢复后通过SyncManager自动增量同步 |
| 数据安全与隐私   | Realm内置加密，支持用户清除本地数据                   |
| 异常情况处理     | 支持手动补录打卡，标记异常状态                        |
| 地图截图Bitmap回收 | 主线程创建Bitmap深拷贝，子线程异步保存，避免高德SDK回收导致崩溃 |
| 缩略图显示失败   | 实现回退加载机制，按raceId推算本地文件路径并自动回写到数据库 |
| 成绩列表重复     | 使用整体刷新策略，避免增量更新导致的数据错乱        |
| 排名更新问题     | 实现智能排名系统：进行中动态计算、结束后锁定排名     |
| 文件分享失败     | 配置FileProvider支持cache-path和files-path，安全分享应用内文件
- 系统自动计算每段耗时与总成绩，支持漏打、超时识别。
- 管理员可一键导出CSV文件，选手可查看个人轨迹与配速分析。

### 1. 基础模块
- **base**：BaseActivity、BaseFragment等基础类
- **db**：Realm本地数据库 + LeanCloud云数据库封装
- **util**：工具类集合（MapThumbnailUtil、QrCodeUtil、GeoFenceUtil等）

### 2. 功能模块
- **location**：定位服务封装（MapLocationManager）
- **service**：后台服务（TrackRecorderService轨迹记录）
- **sync**：数据同步模块（SyncManager、DataConverter、NetworkMonitor）
- **rules**：赛事规则配置

### 3. 界面模块
- **view/welcome**：启动页
- **view/login**：登录注册
- **view/admin**：管理员端（赛事管理、成绩统计、数据导出）
- **view/player**：选手端（赛事列表、打卡、成绩查看）
- **view/race**：赛事相关（创建赛事、路线编辑、地图截图）

### 4项目特色

### 1. 双数据库架构
- Realm本地数据库确保离线可用
- LeanCloud云端数据库实现跨设备同步
- 本地优先策略保证响应速度

### 2. 智能打卡系统
- GPS圆形地理围栏自动触发
- 二维码辅助验证增强可靠性
- 支持离线打卡与延迟同步

### 3. 动态排名机制
- 赛事进行中实时计算排名
- 赛事结束后排名自动锁定
- 避免历史数据被意外修改

### 4. 地图功能增强
- 自动生成赛事路线缩略图
- 支持高德地图POI搜索
- 智能回退加载确保图片显示
